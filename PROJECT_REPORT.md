# Project Report: Simple Rule-Based Chatbot

## 1. Introduction
This project develops a simple text-based chatbot using Python. It responds to user messages using predefined rules.

## 2. Objectives
- Accept user input.
- Clean text using Python.
- Match keywords and phrases.
- Generate responses using if-else conditions.
- Maintain a conversation until the user types bye.

## 3. Technologies Used
- Python
- Regular Expressions
- Conditional Statements
- Loops

## 4. Working Procedure
1. Display a welcome message.
2. Accept user input.
3. Convert input into lowercase.
4. Remove unnecessary punctuation.
5. Match keywords with predefined rules.
6. Display the appropriate response.
7. Repeat until the user types bye.

## 5. Advantages
- Easy to understand.
- Simple Python implementation.
- No internet connection required.

## 6. Limitations
- Understands only predefined keywords.
- Cannot learn new responses automatically.

## 7. Conclusion
This project demonstrates the use of Python, text cleaning, keyword matching, loops and conditional statements to build a simple chatbot.
